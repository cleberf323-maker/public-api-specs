# Public API specifications

This repository contains the public OpenAPI specification for one paid relay.

- Service: DE-LU day-ahead electricity spot prices
- Endpoint: `https://api.datapoint.market/r/digitalworkerapi/de-lu-day-ahead-spot-v2`
- Network: Base (`eip155:8453`)
- Asset: USDC
- Upstream attribution: Energy-Charts.info and Bundesnetzagentur | SMARD.de
- Upstream data license: CC BY 4.0

The specification documents the service contract and its unpaid HTTP 402 response. A 402 challenge is not evidence of a settled payment.
